# 디자인 (혼합안)

앱 이름(가칭): **파크닉** · 슬로건: "공원에서 20분, 배지 하나"

## 혼합안이란
- **UI**(버튼·카드·글자·마커)는 디자인 시스템 v1 그대로 쓴다.
- **지도·캐릭터·배지·일러스트**만 잉크 선 손그림으로 그린다.
- 화면 전체를 손그림으로 만든 스케치안, iOS 기본 스타일안은 채택하지 않았다.

## 파일 보는 법

| 위치 | 내용 |
|---|---|
| `../screens/` | 화면별 PNG. 파일명 앞 번호가 화면 ID |
| `design-tokens.md` | 색·서체·간격·컴포넌트 값 |
| `source/` | 디자인 원본(HTML). 정확한 수치(그림자, 패딩)와 캐릭터·배지의 임시 형태가 여기 있다 |

### 화면 ID 규칙
- **`12*`** = 혼합안 스타일 기준(지도 홈, 공원 시트, 체크인, 배지 획득, 로그인, 캐릭터 선택, 랭킹, 도감, 마이)
- **`03~10*`** = 상태·레이아웃 기준(공원 없음, 체크인 3상태, 이탈·실패·취소, 온보딩, 리뷰, 프로필, 공통 상태). 안의 캐릭터·배지·일러스트는 손그림 스타일로 맞춘다.

### 원본 열어보기
원본은 `.dc.html` 전용 포맷이라 브라우저에서 로컬 서버로 열어야 한다(React를 CDN에서 불러오므로 인터넷 필요).
```
cd docs/design/source
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/Parknic-Design.dc.html
```

## 디자인과 다르게 구현할 것

| 항목 | 디자인 | 구현 |
|---|---|---|
| 위치 권한 문구 | "항상" 허용 안내 (토스트, 07e, 10c, 마이 설정) | **"앱을 사용하는 동안"**으로 변경 |
| 리뷰 키워드 태그 | 리뷰 작성(08e·08f)·목록(08c)·공원 시트에 태그 | 1차 제외. 별점 + 텍스트만 |
| 데모 동작 | "1초 = 1분" 타이머, "공원 밖으로 나가보기" | 구현하지 않음 |
| 손그림 지도 | 지도 전체가 손그림 (12a) | 네이버 지도 SDK 기본 스타일 + 손그림 마커·내 위치·반경 원. 지도 자체 스타일은 가능 여부 확인 후 결정 |

## 에셋 제작 목록
CSS로 그린 임시 형태라 최종 이미지가 필요하다. 코드에서는 이름으로만 참조해 교체해도 코드가 바뀌지 않게 한다.

| 에셋 | 수량 | 비고 |
|---|---|---|
| 캐릭터 | 8종 × 표정 3 | 아바타·시상대·프로필·로그인 일러스트 |
| 공원 유형 배지 | 7종 | 도감·배지 획득·마커 |
| 업적 배지 | 5종 | 첫 배지, 10 / 20 / 50 / 100곳, 7일 연속 (연속은 리본 포함) |
| 마커 아이콘 | 유형 7종 × 상태 3 | 미획득·받은 적 있음·오늘 받음 |
| 일러스트 | 체크인 배경(나무·구름·해), 로그인 배경, 빈 상태·에러·실패 | |
| 앱 아이콘 | 1 | 마스코트 기반 |

## 확인할 점
- 앱 이름 "파크닉" 확정 여부, 상표(KIPRIS)·앱스토어 동명 앱 확인
- 손글씨 서체(개구, Gaegu)는 혼합안 지도 목업의 도로명 라벨에만 쓰였다. 실제 지도는 SDK를 쓰므로 필요 없다. 앱 서체는 Pretendard + Jua.
