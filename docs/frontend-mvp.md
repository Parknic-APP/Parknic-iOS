# 프론트엔드 MVP

> **MVP 목표**: 핵심 루프(공원 찾기 → 체크인 → 20분 → 배지 → 랭킹 → 리뷰)가 실기기에서 끊김 없이 동작하는 iOS 앱을 4주 안에 App Store 심사에 제출한다.
> 구현 설계는 `frontend-design.md`, 화면 ID는 `screens/` 파일명 앞 번호.

## 1. 우선순위

| 등급 | 의미 | 일정이 밀리면 |
|---|---|---|
| **P0** | 없으면 출시 불가 (핵심 루프, 심사 필수) | 무조건 진행 |
| **P1** | 1차에 넣기로 한 기능 | 3주차 금요일에 미완성이면 업데이트로 이동 |
| **제외** | 2차 업데이트 | - |

## 3. 공통 처리 (P0)
- 모든 화면에 **로딩 / 빈 상태 / 에러(재시도)** 정의 (10a, 10b)
- 위치 권한 거부 안내 (10c)
- 네트워크 끊김 시 토스트 안내
- 401 → 토큰 재발급 1회 → 실패 시 로그인 화면
- 서버 에러 코드 → 한글 메시지 매핑 테이블 1곳에서 관리
- 다크 모드는 MVP에서 라이트 고정

## 4. 4주 작업 계획

### 1주차 — 기반
- [ ] 프로젝트 생성, 탭 구조, 디자인 토큰·공통 컴포넌트
- [ ] APIClient, Keychain, 토큰 재발급
- [ ] Apple · 카카오 로그인
- [ ] 온보딩 (닉네임, 캐릭터, 권한)

### 2주차 — 핵심 루프
- [ ] 네이버 지도 래핑, 내 위치, 공원 마커 3상태
- [ ] 공원 상세 시트
- [ ] CheckInTracker: 상태 머신, 백그라운드 위치, 이탈·자정 처리
- [ ] 로컬 알림 (달성, 이탈 경고)
- [ ] 배지 획득 화면
- [ ] **주말: 실제 공원에서 1차 필드 테스트**

### 3주차 — 랭킹 · 리뷰 · 마이
- [ ] 공원 주간 랭킹 시상대
- [ ] 리뷰 목록·작성·수정·삭제·신고·차단
- [ ] 로그아웃·탈퇴·약관 링크
- [ ] P1: 구글·이메일 로그인, 업적, 도움돼요·정렬, 도감·통계·내 리뷰
- [ ] **금요일: 미완성 P1은 업데이트로 이동 결정**

### 4주차 — 안정화 · 제출
- [ ] 실제 공원 3곳 이상 필드 테스트, 배터리 소모 확인
- [ ] 버그 수정, 앱 아이콘·런치 화면
- [ ] TestFlight 배포 → 지인 테스트
- [ ] 스크린샷·스토어 설명 → 심사 제출

## 5. MVP 완료 기준 (출시 전 체크)
- [ ] 화면을 끄고 주머니에 넣은 상태로 20분 측정 → 배지 획득 성공
- [ ] 반경 이탈 후 1분 뒤 실패, 1분 안에 복귀하면 유지
- [ ] 같은 공원 하루 2번 체크인 불가
- [ ] 체크인 20분 동안 배터리 소모 기록 (체감상 부담 없는 수준)
- [ ] 크래시 0건 (TestFlight 기준)
- [ ] 심사 항목: 위치 권한 문구, Apple 로그인, 앱 내 탈퇴, 리뷰 신고·차단, 개인정보처리방침 URL

## 6. MVP에서 제외
