# Parknic-FE

파크닉(Parknic) iOS 앱. 내 주변 공원에서 연속 20분 머무르면 배지를 받고, 공원별 월간 랭킹 시상대에 오르는 공원 산책 수집 앱이다.

- Swift · SwiftUI · iOS 17+ · 네이버 지도 SDK
- 서버: Spring Boot (별도 저장소)
